# Wordleaf · 词芽

安卓离线背单词应用，提供 CET-6、CET-4 和日常学习三种模式。

当前版本 1.3.0（versionCode 4），支持 Android 8.0 及以上。现有包名 `cn.wordleaf.cet6` 保留以兼容已安装版本的进度与更新，应用显示名为「词芽」。

安装包见 [GitHub Releases](https://github.com/qi-fg/wordleaf/releases/latest)。

## 覆盖安装

新版文件：`output/wordleaf-v1.3.apk`。将 APK 传到手机，点击安装，按提示覆盖旧版即可。沿用旧版的包名和签名，保留旧版各模式的学习记录与位置。

安装前建议在旧版「我的 → 备份学习进度」导出一份备份。保留旧版安装，直接更新；卸载会删除本机进度。签名与数据迁移已验证。

## 1.3 界面与学习流程

首页直接显示待学新词、到期复习和本轮进度，右上角只保留模式文字，点击仍可切换。放大单词和中文主要义，统一首页、词库、学习卡、拼写与设置的留白和字体层级。

- **今日学习**：先练最多 20 个到期词，再学剩余新词额度。
- **只学新词**：只取当前计划内尚未学过的词，受每日新词额度限制；已会跳过后补入下一个新词。
- **到期复习**：单独练当前计划的到期词。
- **拼写自测**：看中文释义或听音拼写；学习每组完成后，也可以直接测这组的拼写，再返回原来的词义学习位置。
- **错词强化**：词义与拼写分开强化。拼写结束可选择「只练本轮薄弱拼写」，练本轮中仍有拼写薄弱标记的词，包括写错、使用提示或查看答案的词。

每组完成提示表示完成练习，不表示已经长期记住。同一天补练答对不会立即解除薄弱标记，仍按跨日期独立答对规则安排巩固。途中退出、切换词库或重开应用，保留学习位置和未提交输入。

界面和流程参考了[不背单词官方介绍](https://bbdc.cn/index)及其开发者公开的商店截图，保留词芽自己的界面、内容与复习规则。

## 切换学习模式

点击首页右上角的模式按钮，或「我的 → 学习模式」，选择：

- **CET-6**：5,406 个 ECDICT 六级标签词条，保留原六级词库和词条编号。
- **CET-4**：3,846 个 ECDICT 四级标签词条。
- **日常学习**：1,000 个通用常用词，包括基础词汇。按通用语料参考顺序，从词典带中考、高考、四级、六级或 Oxford 标签的词条中选择。暂不包含按生活场景编排的课程。

各模式分别保存学习计划、进度、收藏、错词和未完成位置；切换回来可以继续原来的学习。同一个词在不同模式中分别记录，统计反映当前模式。升级 1.0 或 1.1 后默认保留六级模式及其记录。

页面已禁用双指缩放，并关闭安卓 WebView 的缩放开关和缩放控件；保留单指滚动和正常输入。

## 时间有限时怎么用

首页点击「调整计划」或「选择计划」，设置路线、范围上限、备考天数、每天投入时间和每日新词目标。

- **重点突破**：按通用语料参考顺序选 100、300、600、1,000 等数量的词，排除主动标记已会的词。保存后，本轮范围固定，首页显示这批词的进度。
- **完整学习**：范围为当前模式的整个词库，保留已会状态。升级 1.0 时先保留完整范围，升级 1.1 时保留已有计划；新安装默认从 300 词开始。
- **自选范围**：选常用层、进阶层、拓展层，可进一步限定收藏词或薄弱词，并限制词数。

计划预览以「范围内未学词数 ÷ 每日新词目标」估算首次覆盖天数，不含复习、遗忘或具体学习速度；超过所选天数会提示缩小范围或调整目标。每天投入的分钟数是你的学习时间目标，累计达到后会在当前练习完成时提醒休息。主动继续会延长提醒窗口，保留已经记录的学习时间。

普通到期复习限定在当前计划范围内，薄弱词入口可练当前模式全部范围中的错词。每日学习先放入最多 20 个到期词，再放入剩余新词额度，避免一轮被复习词无限挤占。其他到期词可通过「到期复习」继续练。

## 词频与词义的依据

来源：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可。四级、六级标签词条不是考试机构发布的官方完整词表。

通用语料参考排序优先使用词典的 BNC 位次，缺失时参考 FRQ；两种语料仅作为选词参考。每个模式按此顺序前 1,500 词归常用层，接下来的 2,000 词归进阶层，其余归拓展层；词库不足时只提供实际存在的层级。这些边界由应用设定，不是真题高低频分界或考试覆盖率。

新版只显示精简中文主要义；不展示英文释义，也不提供展开完整中文义项的入口。原六级前 300 个参考顺位词和例句覆盖词的主要义已核对，共 340 个词。新增词库复用已有主要义，并为基础词提供核对后的释义；其余词从原词库精简，每种词性最多两个义项，最多三种词性，并移除明确标记的专业领域行。没有真题义项频率数据，因此不将这些义项称为已统计验证的「考试高频义」。

在列表、学习卡和拼写题中使用同一份中文主要义，中文搜索也只查这些显示的意思。运行时词库不包含原始英文释义或完整中文义项。数据来源和规则见 `vocabulary-source.json`、`meanings-source.json`、`modes-source.json`。

## 学习与拼写

先回想，再查看中文释义。已会的词可以跳过，不计入新词额度，并会为每日学习或只学新词队列补入下一个未学词。可在详情中重新加入学习。

每完成 5 次练习，可休息、继续或测试这组的拼写。退出或重开应用后保留当前位置、分组状态、重试队列和未提交的拼写输入。「撤销上一次选择」在当前运行期间可以撤销跳过、自评或拼写提交，包括统计和错词记录；重开应用后不保留撤销记录。

拼写提供中文提示和听音模式，提交后逐字指出错写、漏写或多写。忽略大小写、首尾空格，明确收录的英美变体可接受。中文提示可能对应多个近义词，本题测试的是这轮学习的目标词，并提供参考长度。提示、查看答案或未写出目标词会保留在拼写强化队列，不提升词义熟悉程度，也不重复计算今日新词。

原六级首批 200 个词配有应用自编的离线学习例句与中文翻译，其他模式中相同的词复用这些例句。目标词突出显示，翻译默认折叠。不是考试真题原句；未配例句的词明确提示，暂不继续扩充。见 `examples-source.json`。

## 错词与复习

- 词义薄弱与拼写薄弱分别记录；列表按当前薄弱点、历史错误次数和最近错误时间优先排列。
- 「忘记了」：熟悉程度归零，10 分钟后到期，本轮最多再练两次。
- 「有点模糊」：1 天后复习并降低熟悉程度，加入词义强化。
- 「记住了」：按当前熟悉程度，依次安排 1、3、7、14、30、60 天后的复习。
- 每种薄弱点分别在两个不同日期独立答对后解除。同一天反复答对只计一次；新的错误会重新开始。
- 旧版中有遗忘记录且还不熟悉的词会迁移到词义强化；旧版没有错误时间，因此不会编造时间。

统计中同一个词一天内重复练习只计一个「练习词」，词义新词数量、拼写次数、独立拼写正确次数分别记录。

## 重新构建

使用 JDK 和 Android API 35 / Build Tools 35.0.0。SDK、编译输出和签名私钥不入库。安装 JDK（确保 `java`、`javac`、`jar`、`keytool` 可用），在 SDK 中安装 Android API 35 与 Build Tools 35.0.0，然后在 PowerShell 中运行：

```powershell
./build.ps1 -SdkRoot '你的 SDK 目录'
```

构建结果为 `output/wordleaf-cet6.apk`。首次构建会生成自己的本地签名密钥；使用不同密钥生成的 APK 不能覆盖安装项目发行版。更新你自己构建的版本时需要继续保留同一密钥。

已生成的离线词库和释义直接包含在仓库中，不需要重新下载。若要从原始词库重新生成内容，先从上述 ECDICT 来源取得 `tools/ecdict.csv`，将 `app/assets/ECDICT-LICENSE.txt` 复制为 `tools/ECDICT-LICENSE`，再依次运行（需要 Node.js）：

```powershell
node prepare-vocab.cjs
node prepare-examples.cjs
node prepare-meanings.cjs
node prepare-modes.cjs
```

第三步生成主要义后会移除运行时词库的完整释义；重新生成主要义时，应从第一步开始。第四步为四级和日常模式生成离线词库，不改变原六级词条编号。

保留 `tools/wordleaf-signing.jks` 和 `tools/signing-password.txt`，以后仍可用同一签名更新。这两个私有文件不包含在仓库中。预览运行 `node preview.cjs`，打开 `http://127.0.0.1:8765`。浏览器与手机数据相互独立。
