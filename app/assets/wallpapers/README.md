# 内置壁纸

三张风景背景均由本项目通过内置图片生成工具生成，没有采用其他应用的壁纸。AI 生成的场景不代表真实地点摄影。JPEG 为移动端压缩版本，随安装包提供离线兜底。1.3.5 起应用每天后台检查本仓库 `wallpapers.json`，只使用我们维护的图片源；已校验图片缓存在本机，失败时继续使用内置图。

- `lake.jpg`：为背单词 App 制作一张竖版风景照片背景：远处山峦、湖面、薄雾，蓝绿色调。画面留出放置白色文字的空间，不包含文字、图标或界面。
- `forest.jpg`：为背单词 App 制作竖版风景照片背景：清晨薄雾中的森林，柔和的阳光穿过树木，绿色调，画面留出放置白色文字的空间，不包含文字、图标或界面。
- `coast.jpg`：为背单词 App 制作竖版风景照片背景：傍晚宁静的海岸、远处海面和落日余光，蓝色与暖色调，画面留出放置白色文字的空间，不包含文字、图标或界面。

按手机本地日期选图，不承诺每天获取从未出现的新图片。没有手动选择入口。图片清单可以独立于 APK 更新；新图只在首页应用，学习中保持已显示图片。壁纸不是用户学习记录，不包含用户个人信息。
